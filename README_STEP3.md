# D&D Mini — шаг 3: валюта и кошелёк

Шаг 3 добавляет полноценный кошелёк Mini, не отходя от интерфейса через кнопки.

## Что увидит игрок

В личном меню:

- ⚔️ Дейлик
- 👹 Босс
- 🛒 Магазин
- 🎴 Коллекция
- 👤 Персонаж
- 💰 Кошелёк
- 🏆 Рейтинг
- 🔄 Обновить

Кнопка `💰 Кошелёк` открывает личный ephemeral-экран:

- текущий баланс;
- 10 последних операций;
- после каждой операции показывается остаток;
- кнопка `⬅️ Назад`.

Никаких публичных команд для кошелька нет.

## Технически

Добавлен `app/mini/wallet.py`.

Он умеет:

- `get_balance(...)`
- `get_wallet_history(...)`
- `add_coins(...)`
- `spend_coins(...)`

Любое изменение баланса атомарно:

1. блокируется запись SQLite;
2. проверяется текущий баланс;
3. обновляется `mini_players.coins`;
4. создаётся запись в `mini_wallet_transactions`;
5. всё коммитится одной транзакцией.

Баланс не может стать отрицательным.

Добавлен `operation_key`: позже дейлики, боссы и покупки смогут безопасно
повторить запрос после сбоя, не начислив/не списав монеты дважды.

## Доходов пока нет

На этом шаге кошелёк у нового игрока показывает 0.
Это ожидаемо.

Первый реальный источник валюты появится на шаге 4 — ежедневный бой.
Босс и магазин позже будут использовать тот же кошелёк.

## Обновление сервера

Архив кумулятивный. Замени:

- `bot.py`
- `requirements.txt`
- `app/handlers/__init__.py`
- всю папку `app/mini/`

`shpakdnd.db` НЕ заменять.

После загрузки:

```bash
cd /opt/shpakdnd-bot
./.venv/bin/pip install -r requirements.txt
sudo -u shpakbot ./.venv/bin/python -m compileall -q bot.py app
systemctl restart shpakdnd-bot
systemctl status shpakdnd-bot --no-pager
```

Существующая база мигрируется автоматически: таблица транзакций получает
`operation_key`, данные игроков не удаляются.
