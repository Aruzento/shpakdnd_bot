# Аудит графа сценария

- Оригинал: «Тайна пропавшей овцы», **46 сцен + 7 концовок = 53 узла**, **113 выборов**.
- Все ссылки разрешаются; все узлы достижимы из `scene_1`, все семь концовок достижимы.
- В исходном графе есть циклы, например `scene_39 → scene_40 → scene_39`.
- **Скрывать только уже посещённые сцены недостаточно**: кратчайший найденный тупик при наивной фильтрации (12 сцен): `scene_1 → scene_2 → scene_6 → scene_13 → scene_24 → scene_25 → scene_26 → scene_16 → scene_10 → scene_11 → scene_21 → scene_14`. В последнем узле обе цели уже были посещены.
- Требуется дополнительно скрывать варианты, которые не позволяют достичь *ни одного ещё не пройденного финала* без повторов (`can_reach_ending`).
- Провёл вне репозитория 10 000 случайных прогонов с алгоритмом фильтрации `not visited` + `can_reach_ending`; все завершились, обнаружены все 7 концовок; максимальная длина в пробе — 27 узлов. Это **иллюстративная offline-проверка**, а не доказательство интеграции с ботом.
- Предлагаемый JSON использует новый контракт `schema_version: 2`, `visit_policy: once`; текущий движок принимает **только v1 DAG**, этот JSON нельзя копировать в рабочий `STORIES_DIR` до обновления, тестов и staging.
- Идентификаторы авторских маркеров: `scene_1`…`scene_46`, `ending_k1`…`ending_k7`. Для текущего сеанса `visited` извлекается из `story_steps` и текущего `node_id`.
- Слова автора не переписаны: технически убрана Markdown-разметка `**` из текста, добавлены исходные заголовки сцен/концовок к тексту, служебные разделители и навигационные стрелки перенесены в структуру JSON. Описания и последовательность выборов сохранены.
