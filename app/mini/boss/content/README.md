# Контент боссов D&D Mini

Вся контентная часть босса изолирована внутри `app/mini/boss/content`.

- `bosses.json` — характеристики боссов и их награды.
- `items.json` — предметы-награды боссов. Они синхронизируются в `mini_items`, но их эффекты пока не применяются.
- `images/` — изображения боссов. В `bosses.json` указывается только имя файла.

Поля босса:
- `code`, `name`, `description`;
- `max_hp`;
- `min_players`;
- `reward_coins` — базовая награда в монетах каждому участнику;
- `reward_items` — список `{code, quantity}`;
- `reward_shields` — сколько ударов босса по награде сначала поглощают щиты;
- `reward_decay_percent` — на сколько процентных пунктов уменьшается денежная награда после щитов;
- `image`;
- `active`.

Бой:
- участники ходят строго по очереди;
- на ход даётся `boss_skip_hours` из `mini_worlds` (сейчас 4 часа);
- пропущенный игрок возвращается в следующем раунде;
- в конце каждого раунда босс атакует награду;
- сначала ломаются щиты, затем падает процент денежной награды;
- если процент награды дошёл до 0 — бой проигран, предметы и монеты не выдаются, каждый участник получает `reward_coins // 10` общих осколков;
- при победе каждый зарегистрированный участник получает текущую денежную награду и все предметы из `reward_items`.

Предметы пока являются только объектами инвентаря. Их активные эффекты будут добавлены отдельным этапом.
