Сюда кладутся картинки героев для гачи.

Поддерживаемые форматы для будущей отправки в Telegram: JPG/JPEG, PNG, WEBP.
Рекомендуемый размер: квадрат 768x768 или 1024x1024.
В heroes.json у героя поле "image" должно содержать только имя файла, например:
"image": "torvin.webp"

Файл _placeholder.png можно оставить как временную заглушку.
