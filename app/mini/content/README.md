# Контент D&D Mini

Эта папка специально вынесена отдельно от логики бота.

## Магазин

Файл: `shop.json`

Основные поля товара:

- `code` — уникальный технический код, лучше не менять после первых покупок;
- `category` — категория из блока `categories`;
- `title` — название на кнопках и карточке;
- `description` — описание товара;
- `price` — цена в Mini-монетах;
- `delivery` — `inventory` или `certificate`;
- `stock` — общий лимит продаж, `null` = без лимита;
- `max_per_player` — лимит покупок одним игроком, `null` = без лимита;
- `active` — показывать ли товар в магазине.

Для `delivery = inventory` нужен вложенный объект `item`.
Для `certificate` товар хранится как непогашенный сертификат в истории покупок.

Каталог перечитывается при каждом открытии магазина. После правки `shop.json`
перезапуск бота обычно не нужен.

## Герои / гача

Файл: `heroes.json`

Картинки: `hero_images/`

У каждого героя есть:

- `code` — уникальный технический код;
- `name` — имя;
- `rarity` — `common`, `uncommon`, `rare`, `legendary`;
- `race` — раса;
- `class_name` — класс;
- `attack` — базовая сила для будущих боссов;
- `passive_key` — технический код пассивки;
- `passive_text` — текст способности;
- `description` — описание героя;
- `image` — имя файла из `hero_images/`;
- `active` — участвует ли герой в гаче.

В `settings` отдельно лежат цена крутки, веса редкостей и награды за дубликаты.

На шаге 5 магазин уже работает. Саму крутку подключим на шаге 6, но структура
героев и картинок уже готова и проверяется ботом.
