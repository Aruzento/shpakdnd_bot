# Авторские изображения рейдовых боссов

Эти четыре изображения предоставлены владельцем 26.10.2026 в одном сообщении,
в порядке «босс №1…№4». JPG перекодированы в настоящий PNG (1280×1280),
без перерисовки, кадрирования и изменения размеров. Технические порядковые
имена выбраны по прямой просьбе переименовать и разместить изображения.
Это имена файлов, не вымышленные игровые code/name.

PNG. Наличие изображений само по себе не создаёт босса и не запускает рейд.
