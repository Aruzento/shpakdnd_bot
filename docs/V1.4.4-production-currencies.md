## Каталог и торговля

Оригинал и постоянный индекс сохраняют все 4450 строк и их стабильные code.
Новая runtime-сборка содержит 4435 обычных товаров для каждой выбранной темы.
Все 15 точных денежных названий источника исключены, включая три основные монеты
и 12 связок. Обычный «Кошель с монетами» остаётся товаром: поиска по слову
«монета» нет. Денежный code нельзя включить через shop_offers.csv.

Полный исторический runtime из 4450 строк совместим, если все его денежные
позиции buy_enabled=false. Они не регистрируются новыми предметами и не
участвуют в торговле. При публикации новой сборки старые связи SKU/item_id/sold
и registry/inventory/журнал не удаляются; старые catalog entries становятся
неактуальными. Серверная проверка блокирует денежные SKU независимо от UI
и старой кнопки. Удалённые code остаются в постоянном индексе.

Новые покупки, выплаты, сдача и credit redeem используют три физические монеты.
Пример -m: 35000 исходных медных → 3.5 золотых; 3% → 0.105 золотых,
то есть 10 серебряных и 50 медных. Fraction/Decimal, без округления.
Непредставимые целыми монетами суммы сохраняются целиком в точном credit.
Нет автоматического ассортимента: только явно рассмотренные buy_enabled=true
для обычных товаров; отсутствие offers означает пустой список покупки.

## Ограничения -b

Формула -b не менялась: 35000 × 0.000285 = 9.975 универсальных золотых.
Масштаб 100 универсальных медных = 1 универсальная золотая отличен от -m.
Существующий universal preflight и явно утверждённые профили остаются обязательны;
новые выплаты/списания в подтверждённом профиле идут только тремя его монетами.
Production-профиль 100/100 выше предназначен для -m и не даёт права включать -b.
Для старого -b с расширенным master сохраняется совместимость; создание -b
в новой теме по оригинальному каталогу требует отдельного архитектурного
рассмотрения. Не регистрировать ради него 12 справочных связок.

import fcntl
import hashlib
import os
from pathlib import Path
import tempfile

repo = Path(__import__('sys').argv[1]).resolve()
directory = Path('/var/lib/shpakdnd')
assert directory.resolve() == directory and directory.is_dir()
sources = {
    'loot.csv': '7bffd8a9b8314651318c961838c9b6b872f5d02b6cd896e968f9226c7bcdfe20',
    'loot_code_map.csv': 'b0203b22415a05e668f9d823d6b75aba98fe0aeff75ef5459c8e1754fb49141a',
}
prepared = {}
for name, expected in sources.items():
    data = (repo / 'data' / name).read_bytes()
    assert hashlib.sha256(data).hexdigest() == expected, name
    data.decode('utf-8', errors='strict')
    prepared[name] = data
# Только пустой bootstrap runtime; полный каталог не строится/не активируется.
prepared['shop.csv'] = b'chat_id,thread_id,code,name,description,price,stock,active\n'
with (directory / 'shop.csv.lock').open('a+b') as lock:
    fcntl.flock(lock, fcntl.LOCK_EX)
    for name, data in prepared.items():
        target = directory / name
        if os.path.lexists(target):
            assert target.is_file() and not target.is_symlink(), name
            if name in sources:
                assert hashlib.sha256(target.read_bytes()).hexdigest() == sources[name], (
                    name + ': existing source differs; stop for explicit review'
                )
            print('PRESERVED', target)
            continue
        staged = None
        try:
            with tempfile.NamedTemporaryFile(dir=directory, prefix='.prepare-',
                                             delete=False) as out:
                staged = Path(out.name)
                out.write(data)
                out.flush()
                os.fsync(out.fileno())
            os.chmod(staged, 0o640)
            # Link is atomic and refuses to clobber a concurrently created target.
            os.link(staged, target)
            print('CREATED', target)
        finally:
            if staged is not None:
                staged.unlink(missing_ok=True)
    fd = os.open(directory, os.O_RDONLY | os.O_DIRECTORY)
    try:
        os.fsync(fd)
    finally:
        os.close(fd)
