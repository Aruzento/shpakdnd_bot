# Предложение наград за концовки — НЕ УТВЕРЖДЕНО

Технически регистрируются достижения user_id/story_code/ending_id только у активных участников
при атомарном завершении. Выплаты отсутствуют, ресурсные сообщения не отправляются.
Уже полученные достижения не означают право на автоматическую ретро-выплату.

Вариант на согласование: одинаковая награда за любую первую концовку, без разницы сложности,
чтобы не навязывать игрокам один выгодный маршрут.

| Концовка | Предложение Mini | Осколки/билеты/предметы |
|---|---:|---:|
| K1 | 5 монет | 0 |
| K2 | 5 монет | 0 |
| K3 | 5 монет | 0 |
| K4 | 5 монет | 0 |
| K5 | 5 монет | 0 |
| K6 | 5 монет | 0 |
| K7 | 5 монет | 0 |

Максимум 35 монет игроку за всю историю: примерно 1,17 обычного призыва по цене 30.
Повторные прохождения одной концовки ничего не добавляют. Это предложение, не игровая настройка.
Альтернатива с нулевым влиянием на экономику — только семь отметок достижения.

Для D&D требуется отдельное решение владельца о валюте/номинале и получателе: нельзя
автоматически конвертировать награду в Mini, создавать кошелёк либо одновременно платить в
двух режимах. Уникальность уже общая по Telegram user ID, независимо от выбора D&D/Mini.

До включения согласовать: суммы, единицу валюты D&D, правила получателя, ретроактивность,
миграцию payment-claim и независимую проверку экономики. Тогда receipt выплаты с UNIQUE
(user_id,story_code,ending_id,policy_version) и wallet ledger должны фиксироваться в одной
SQLite-транзакции; повторный callback/uncertain Telegram не являются основанием платить снова.
Сейчас этой экономической операции нет и флага, способного случайно её включить, тоже нет.
