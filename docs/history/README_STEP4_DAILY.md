# D&D Mini — шаг 4: ежедневный бой

Работает полностью через кнопку `⚔️ Дейлик` в личном ephemeral-меню.

Что происходит:

1. Игрок нажимает `⚔️ Дейлик`.
2. Бот генерирует короткое случайное приключение с Mini-персонажем.
3. Игрок получает Mini-монеты.
4. Результат сохраняется в `mini_daily_claims`.
5. Баланс и история кошелька обновляются в той же SQLite-транзакции.
6. Повторное нажатие в тот же день показывает то же приключение, но второй раз монеты не выдаёт.
7. На следующий календарный день дейлик снова доступен.

День считается по `BOT_TIMEZONE` из `.env` / `app/config.py`.
По умолчанию это `Europe/Moscow`.

Награды:

- обычное событие: 3–6 монет;
- редкое событие: 7–10 монет;
- очень редкое событие: 15 монет.

Вероятности:

- 90% обычное;
- 9% редкое;
- 1% очень редкое.

Тексты генерируются из набора противников, завязок, ситуаций и концовок.
Даже без будущего расширения получается несколько тысяч комбинаций.

После дейлика игрок видит только две кнопки:

- `💰 Кошелёк`
- `⬅️ Назад`

Никаких новых slash-команд не добавлено.

## Установка

Архив содержит полного бота. Распакуй поверх `/opt/shpakdnd-bot`,
не заменяя `.env` и `shpakdnd.db`.

После загрузки:

```bash
cd /opt/shpakdnd-bot
chown -R shpakbot:shpakbot /opt/shpakdnd-bot
./.venv/bin/pip install -r requirements.txt
sudo -u shpakbot ./.venv/bin/python check_bot.py
sudo -u shpakbot ./.venv/bin/python -m compileall -q bot.py app
systemctl restart shpakdnd-bot
systemctl status shpakdnd-bot --no-pager
```

Старый закреп D&D Mini менять не нужно.
Кнопка `⚔️ Дейлик` внутри личного меню начнёт работать после рестарта.
