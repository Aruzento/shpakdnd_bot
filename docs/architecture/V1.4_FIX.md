# D&D Mini V1.4 — FIX после аудита

Ветка `codex/v1.4`, базовый коммит `d71b55f`. Изменения ограничены Village,
Shadow ability infrastructure / Boss snapshots, cross-content validation и
Grave Seal. Текущий Shadow/Mythic content, изображения, Arise chances и
несвязанный баланс не изменены. Новых таблиц/миграций нет.

## 1. Village: stars + 1

`base_rate × (actual_stars + 1)` применяется к охоте, шахте и рынку. Ограничение
`min(stars, 6)` удалено. Common 0/1/5★ производит .125/.25/.75 в час;
Legendary/Shadow 0/1/5/10★ — 1.25/2.5/7.5/13.75 в час.

Все значения хранятся в прежних целых units 1/(32*3600); boosts +25% сохраняют
точность, поскольку базовые rates кратны четырём. Settlement перед upgrade
и Shadow duplicate, остатки при collect, food gating и 8-hour cap сохранены.
Fixtures теперь покрывают 0★, высокий stars, старый/будущий interval без
предварительного чтения state, односекундные остатки и boost intersections.

## 2. Shadow abilities и immutable Boss loadout

Добавлены только canonical passive keys и эффекты, без записей Shadow heroes:

| Passive | Реализация |
|---|---|
| shadow_collapse | Каждый третий primary — fixed hit `snapshot.base_attack × 2`; игнорирует ordinary damage modifiers, сохраняет физическую reachability |
| shadow_waste_of_time | Каждый третий primary даёт hero-side 0 и сохраняет `shadow_pending_double`; следующий primary потребляет его и вызывает один обычный extra hit |
| shadow_transformation | Один случайный executable creature trait и текущая faction босса выбираются при старте, до shared creature hooks |
| shadow_oneshot | Existing declarative `every_n_damage_multiplier`, every=5, multiplier=300% |
| shadow_simple | Только primary обходит incoming faction/creature/Boss damage modifiers; использует текущую attack со stars |

Collapse и zero пропускают ordinary modifiers, potion и class amplification.
После hero-side damage mode всегда применяется absolute Boss final rule;
он может заменить fixed result. Это уточнено отдельным FIX поверх `bcee3fc`.
Simple отключает incoming modifiers; собственные outgoing class bonuses и
зелье сохраняются. Его pure mode не распространяется на extra hits, сохранённое
эхо или poison tick. Все extra hits обходят passive resolver и primary counter;
после смерти от первого удара double второй не вызывается. Waste extra проходит
тот же обычный damage lifecycle, включая party class / potion / armor и текущий
class state до primary, без повторного passive trigger.

Новый loadout сохраняет `base_attack` из `mini_heroes.attack` до stars/potion
и бонусов. В активном бою live hero catalog не читается для Collapse.
**Legacy fallback:** если поля нет, используется сохранённая participant battle
`attack`; это не реконструкция исторической базовой атаки. Сам старый snapshot
не дополняется live значением. При отсутствии Shadow passives старые бои
сохраняют прежний расчёт. Старые versions и recovery не переписываются.

Transformation хранит `shadow_form` в persisted hero state, а combat-effective
faction/special_trait — в immutable snapshot, завершённом внутри start transaction.
Поэтому все существующие shared consumers snapshot видят одну форму до конца
боя, включая creature battle_start, reachability и regeneration counters.
Выбор через injectable chooser / patchable secrets.choice; открытые metadata
теги, none и boss ability исключены. Признанные legacy aliases нормализуются.
Новый бой выбирает новую форму; restart ничего не выбирает повторно.

## 3. Cross-content Shadow mapping

Canonical mapping остаётся `boss.shadow_hero_code -> hero.code`. При загрузке
Boss catalog каждый явный mapping обязан указывать на существующего героя
rarity=shadow, включая non-extractable bosses. Unknown/non-shadow mapping даёт
BossCatalogError на validation/startup. Обычный bot.py startup вызывает
loader до инициализации БД и Telegram, поэтому invalid mapping не может
незаметно дойти до Arise. Отсутствующий mapping, пустой Shadow
catalog и Training Dummy с shadow_extractable=false валидны. Runtime mapping
по shadow_of не добавлен; legacy runtime no-op для исчезнувшего counterpart
сохранён. Arise: Hobgoblin 1%, Drow 5%, SonDzhi 10%, без изменений.

## 4. Grave Seal и One Punch

Единая таблица lifecycle stages классифицирует suppressible active abilities
по ability_key. oneshot включён в turn stage; hydra/transformation остаются
в after-turn stage. Потребление Seal выполняет общий helper без boss_code.

При подавленном oneshot только локальный attack plan использует ability=none
и decay=10%. Persisted ability/decay остаются oneshot/100%; shield lifecycle,
temporary reward HP и class reward accounting выполняются обычным путём.
Следующий boss turn снова Van Shot. Seal не отменяет весь ход и не блокирует
passive creature regeneration. Existing critical_strike, paralysis, banishment,
rapier, hydra_regeneration и transformation проходят regression.

## FIX damage precedence поверх bcee3fc

Причина бага: ветки fixed/incoming_pure возвращали результат до
boss_abilities.final_hero_damage(). Pure hero modes тем самым обходили
абсолютные правила босса, хотя должны пропускать только ordinary modifiers.

Теперь у calculate_hit один общий завершающий слой:

1. Hero passive resolution.
2. Выбор normal/fixed/incoming_pure.
3. Ordinary modifiers применяются или пропускаются согласно mode.
4. Разрешённые outgoing bonuses дают hero-side damage.
5. final_hero_damage() вызывается ровно один раз для любого mode.
6. Boss effects/events объединяются, HP рассчитывается с healing и max_hp cap.

Normal pipeline и сам final_hero_damage не менялись. Raw damage сохраняет
прежний смысл: результат hero passive до faction, potion, incoming modifiers
и beast amplification. base_attack параметр финального слоя передаётся по
прежнему контракту; frozen base_attack для Shadow Collapse не меняется.

- Inversion: Shadow всегда 0, остальные rarity сохраняют raw +100/+50,
  raw 25%/1%, Mythic heal от raw с cap.
- Dummy: каждый фактический hit равен 1, включая Waste zero-primary и каждый
  hit последующего double; extra не увеличивает primary counter.
- Simple Village Guy: final возвращает прежний raw passive damage. Например,
  Shadow Simple raw 64 остаётся 64 при potion/class bonuses; Collapse raw 28
  остаётся 28. Повторного применения modifiers нет.
- Waste of Time boss: rare/legendary/mythic дают 0, Shadow не блокируется.

Фундаментальная reachability сохраняется: невозможность фактического попадания
не превращается в hit из-за финального правила Dummy/Simple. Для недостижимого
Shadow hit raw передаётся как 0; normal mode сохраняет прежний контракт.

Новый test_damage_precedence.py содержит 26 regression tests с fixtures:
все 24 запрошенных комбинации, skip ordinary modifiers / final exactly once,
raw/Mythic HP/events и persisted Waste double по Dummy после restart.
В test_fixes.py исправлены прежние ожидания обхода абсолютных Boss rules;
проверки обхода ordinary modifiers сохранены.
