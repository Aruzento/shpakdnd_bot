# ADR: навигация и составные операции V1.4.2

Дата: 2026-10-12. Дополняет ADR V1.4.2, исторические решения не переписываются.

Карты 109 экранов — спецификация, а не runtime-программа. Сохраняются Python
builders и whitelist handlers. Макеты/исходная матрица/решения конфликтов и
фактическая матрица хранятся рядом. Формы JSON эквивалентны, не внедряются дважды.
Новый JSON hot-reload не вводится; будущий loader требует отдельного контракта
schema/atomic reload/last-known-good. Экономика остаётся в сервисах.

×10 использует извлечённый внутренний стандартный pull в той же транзакции:
одна оплата, фиксированная стоимость пакета, 10 последовательных состояний.
mini_gacha_batches фиксирует parent/result/key, mini_gacha_pulls хранит десять
обычных записей. Ownership/luck/pity читаются заново после каждого исхода.
Повторный token возвращает пакет, новый token создаёт новый пакет.

Приватный ввод имени связан с owner/world и TTL в mini_registration_sessions.
Создание и starter gift атомарны. Не хранится произвольный код/ввод для сценариев.
Collection origin содержит только whitelist route, страницу и валидируемый
компактный filter token; сущность заново проверяется сервером. Footer имеет
логического parent, а не произвольный next_msg_id из исторического макета.

Tower retry — отдельный сервис, PK на previous_attempt_id исключает повторную
новую попытку; FK new_attempt_id сохраняет результат при рестарте. Выбор героя
этажа независим от активного героя Mini. Boss selector остаётся совместимым.
Работник переводится в два явных шага; settled accrual и revision сохранены.

mini_public_shares фиксирует at-most-once claim до Telegram. Отсутствие
транзакции между SQLite и Telegram означает возможную потерю публикации при
crash/timeout. Повторное награждение или списание не зависит от сети.

Прежний код игнорирует новые таблицы, но не понимает новые callback/session.
Смена кода и пары code/backup требуют отдельной процедуры. Схема не удаляется
и рабочая SQLite не заменяется тестовой. Автоматический аудит не заменяет
Telegram-стенд с отдельным ботом и независимое ревью финального diff.
