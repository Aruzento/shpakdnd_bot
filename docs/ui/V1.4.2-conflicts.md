# Решения по девяти конфликтам (до реализации)

1. Дома и Жильцы доступны одновременно; карточка жильца ровно три действия.
2. Добавление на работу только свободных жителей; перевод через явное снятие. Старое назначение из карточки не выполняется.
3. Mythic находится в Ещё и возвращается туда.
4. Кнопка регистрации открывает безопасную личную сессию имени; /minicreate сохранён; результат home и разовый подарок.
5. Три купона: выбор типа, подтверждение, общий use_item и стандартный результат без pity.
6. ×10: десять последовательных обычных исходов в одной транзакции за 10 цен; сохранённый пакет, свежие action tokens.
7. Башня: редкость, список, карточка; legacy selector сохраняется, Boss selector не меняется; retry создаёт одну новую попытку.
8. Продажа осколков доступна из карточки при наличии; курс сохранён.
9. Возвраты сохраняют контекст коллекции; остальные логические родители с fallback.

Карты являются источником макетов, не исполняемой конфигурацией. Python строит кнопки и проверяет права/состояние. Цвет поддерживается текущей aiogram и безопасно опускается при несовместимости.
