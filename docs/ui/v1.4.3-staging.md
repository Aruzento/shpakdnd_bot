# V1.4.3 — матрица реального Telegram staging

Статус всех строк: НЕ ВЫПОЛНЕНО. Автотесты не заменяют эти проверки. Отдельный токен, world, Telegram Mini-тема, SQLite и конфигурация обязательны; production запрещён. Здесь секреты не хранить.
