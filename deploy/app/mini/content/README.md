# Контент D&D Mini

Эта папка специально вынесена отдельно от Python-логики. Большую часть наполнения
можно менять обычным редактированием JSON и заменой картинок.

## Магазин — `shop.json`

Основные поля товара:

- `code` — уникальный технический код; после первых покупок лучше не менять;
- `category` — категория из `categories`;
- `title` — название;
- `description` — описание;
- `price` — цена в Mini-монетах;
- `delivery` — `inventory` или `certificate`;
- `stock` — общий запас, `null` = без лимита;
- `max_per_player` — лимит на игрока, `null` = без лимита;
- `active` — показывать ли товар.

Для `delivery = inventory` нужен объект `item`.

`Билет призыва` (`summon_ticket`) теперь работает: игрок может купить его и
потратить вместо монет на одну крутку.

## Герои и гача — `heroes.json`

Картинки героев лежат в:

`app/mini/content/hero_images/`

У каждого героя:

- `code` — уникальный код; после выдачи героя игрокам лучше не менять;
- `name` — имя;
- `rarity` — `common`, `uncommon`, `rare`, `legendary`;
- `race` — раса Mini-персонажа при выборе героя активным;
- `class_name` — класс Mini-персонажа;
- `attack` — базовая атака для будущих боссов;
- `passive_key` — технический код будущей боевой пассивки;
- `passive_text` — текст способности;
- `description` — описание героя на карточке;
- `image` — имя файла из `hero_images/`;
- `active` — участвует ли герой в новых крутках.

Пример:

```json
{
  "code": "torvin_ironbeard",
  "name": "Торвин Железнобород",
  "rarity": "rare",
  "race": "Дворф",
  "class_name": "Варвар",
  "attack": 8,
  "passive_key": "stubborn",
  "passive_text": "Первый промах по боссу можно будет перебросить.",
  "description": "Дворф, который считает тактикой всё, что заканчивается ударом топора.",
  "image": "torvin.webp",
  "active": true
}
```

А файл картинки:

`app/mini/content/hero_images/torvin.webp`

Поддерживаемый Telegram формат удобно держать в PNG/JPG/WEBP. Для единообразия
лучше делать квадратные карточки, например 1024×1024.

## Настройки гачи

В `heroes.json` → `settings`:

- `pull_price` — цена крутки за монеты;
- `ticket_item_code` — код билета в магазине;
- `rarity_weights` — веса редкостей;
- `duplicate_shards` — сколько осколков даёт повторный герой.

Если в какой-то редкости пока нет активных героев, её вес временно не участвует
в розыгрыше. Когда добавишь героя этой редкости, вес начнёт работать автоматически.

Каталог героев синхронизируется при открытии гачи/коллекции и при старте бота.
Изменения текста и картинок обычно достаточно сохранить на сервере; для максимально
предсказуемого обновления после больших правок можно перезапустить сервис.


## Улучшения героев

Настройки находятся в `heroes.json` → `settings.upgrade`.

- `attack_growth_percent` — рост атаки за каждую звезду;
- `shard_sell_price` — монет за 1 проданный осколок;
- `star_cost_base` — базовая часть формулы цены;
- `max_stars` — лимит звёзд по редкости (`null` = без лимита);
- `cost_multiplier` — множитель стоимости по редкости.

Количество звёзд хранится отдельно для каждого героя каждого игрока в БД.
Базовую атаку по-прежнему редактируй в поле `attack` самого героя.
