# D&D Mini — шаг 2

Добавлено:

- `/mini` — главное меню D&D Mini;
- `/minicreate "Имя персонажа"` — создание Mini-персонажа самим игроком;
- стартовый экран с кнопками;
- карточка Mini-персонажа;
- идентификация игрока по Telegram user ID;
- защита меню: чужие кнопки нажимать нельзя;
- автоматический `init_mini_db()` при запуске бота.

## Главное меню

После создания персонажа `/mini` показывает:

- имя Mini-персонажа;
- активного героя (пока не выбран);
- баланс Mini-монет;
- кнопки Дейлик / Босс / Магазин / Коллекция / Персонаж / Рейтинг.

Пока реально работает раздел «Персонаж». Остальные кнопки являются точками входа
для следующих шагов и сообщают, что функция ещё не реализована.

## Создание

Примеры:

`/minicreate "Дед Максим"`

или

`/minicreate Дед Максим`

Игрок создаёт персонажа только самому себе в текущем Mini-мире.
Один Telegram-пользователь может иметь по одному Mini-персонажу в каждом Mini-мире.

## Что копировать на сервер

Архив кумулятивный: в `app/mini/` лежит весь Step 1 + Step 2.

Заменить/добавить:

- `bot.py`
- `app/handlers/__init__.py`
- всю папку `app/mini/`

`shpakdnd.db` НЕ заменять.

После загрузки:

```bash
cd /opt/shpakdnd-bot
sudo -u shpakbot ./.venv/bin/python -m compileall -q bot.py app
systemctl restart shpakdnd-bot
systemctl status shpakdnd-bot --no-pager
```

Если Mini-мир ещё не зарегистрирован, один раз выполни Step 1 setup:

```bash
sudo -u shpakbot ./.venv/bin/python -m app.mini.setup \
  --chat-id CHAT_ID \
  --thread-id TOPIC_ID \
  --name "D&D Mini"
```
