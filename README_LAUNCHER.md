# D&D Mini — закреплённый launcher

Основная точка входа теперь не `/mini`, а одно публичное закреплённое сообщение.

## Как установить launcher

В зарегистрированной Mini-теме администратор один раз пишет:

`/minipanel`

Бот:

1. проверяет, что команду вызвал администратор темы;
2. публикует карточку D&D Mini с кнопкой `🎮 Открыть D&D Mini`;
3. пытается сам закрепить карточку;
4. сохраняет ID launcher-сообщения в `mini_worlds`;
5. пытается удалить одноразовую команду `/minipanel` из истории.

Если у бота нет права закреплять сообщения, карточка всё равно создаётся —
её нужно закрепить вручную.

## Что видит игрок

Все видят только общий закреп:

`🎲 D&D Mini`
`[🎮 Открыть D&D Mini]`

После нажатия Telegram показывает только этому игроку ephemeral-меню
вместо общего launcher. Для остальных закреп не меняется.

Если персонаж уже есть — сразу открывается главное меню.
Если персонажа нет — открывается личный экран создания.

## Команды

`/mini` оставлен в коде как технический резерв, но убран из меню команд Telegram.

`/minicreate "Имя"` остаётся только для ввода произвольного имени персонажа
и зарегистрирован как ephemeral-команда — её не видят остальные участники.

`/minipanel` не показывается в меню команд. Это одноразовая команда администратора.

## Что обновить на сервере

Архив кумулятивный. Замени:

- `bot.py`
- `requirements.txt`
- `app/handlers/__init__.py`
- всю папку `app/mini/`

`shpakdnd.db` НЕ заменять.

После загрузки:

```bash
cd /opt/shpakdnd-bot
./.venv/bin/pip install -r requirements.txt
sudo -u shpakbot ./.venv/bin/python -m compileall -q bot.py app
systemctl restart shpakdnd-bot
systemctl status shpakdnd-bot --no-pager
```

После успешного рестарта в Mini-теме:

`/minipanel`

Для автоматического закрепления боту нужно право закреплять сообщения.
Для автоматического удаления `/minipanel` из истории — право удалять сообщения.
