# Mini admin grants

В теме D&D Mini администратор темы может выдавать игрокам монеты и предметы.

## Монеты

```text
/admadd @user -c 100
```

Также принимается:

```text
/admadd @user -c "100"
```

Монеты начисляются через обычный Mini-кошелёк и попадают в историю операций.

## Предмет

```text
/admadd @user -i 3
```

Число после `-i` — `id` из таблицы `mini_items`. Выдаётся 1 экземпляр.

Посмотреть доступные ID без sqlite3:

```text
/admitems
```

## Совместимость

Старая глобальная команда `/admadd CHAT_ID[:TOPIC_ID] @username предмет`
для обычного D&D-инвентаря сохранена. Новый Mini-синтаксис определяется по форме
`@username -c/-i` и работает только внутри темы D&D Mini.
